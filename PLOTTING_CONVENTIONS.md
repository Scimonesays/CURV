# CURV Plotting Conventions

- Save plots as `.png` (optional `.pdf` mirror is allowed).
- Plot filenames must include `run_id` and `plot_type`.
- Interactive-only plots are not valid as sole artifacts.
- Store plots at `results/artifacts/<run_id>/plots/`.
- Store metric tables at `results/artifacts/<run_id>/metrics/`.
- Record all artifact relative paths in registry `artifacts` columns.
